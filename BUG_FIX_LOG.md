# Bug Fix Log – BITS Digital CodeForge V1.0

Every bug below was reproduced in the original file first, fixed in `stage1-bugfix/index.html`, and retested there. The same fixes carry over into the redesigned console (`index.html`). Test spreadsheets are in `test-data/`.

| # | Bug / Issue Identified | How You Reproduced It | Root Cause | Fix Implemented | How You Tested the Fix |
|---|---|---|---|---|---|
| 1 | Course dropdown shows one entry per student, and courses from an earlier file stay after a new upload | Uploaded `sample_marks.xlsx` (300 rows, 3 courses): the dropdown had 301 options. Uploaded `second_upload.xlsx` next: 356 options, with the 3 old courses still listed. Picking an old course showed Avg `NaN` | `file.onchange` added an `Option` for every row (`data.map(d=>d.Course).forEach(...)`) and never removed the options from the previous file or reset the selected course | Reset the list to the placeholder (`course.length=1`), add each course once using a `Set`, sort them, and clear the grading view and selection when a new file is loaded | Same two uploads: 3 courses after the first, only the 2 new courses after the second, grading view cleared |
| 2 | Min and Max statistics are swapped | Opened PHY F111: the box labelled Min showed 92 and Max showed 25 | In the HTML the "Min" box wraps `id="max"` and the "Max" box wraps `id="min"`, so `computeStats` writes each value into the wrong box | Swapped the two ids | PHY F111 now shows Min 25, Max 92; checked against the spreadsheet |
| 3 | File picker only offers `.xls`, but the input file is `.xlsx` | Clicked Choose File: `.xlsx` files are greyed out / hidden in the dialog | `accept=".xls"` on the file input | `accept=".xlsx,.xls"` | `.xlsx` files are selectable and load |
| 4 | Students above the A max or below the E min get no grade and silently disappear from the CSV | Set A Max to 95: no error, download stayed enabled, students with 96–100 were missing from the CSV. Same with E Min = 5 | `validateRanges` only checked Min < Max and adjacency between grades. Nothing checked that A reaches 100 and E starts at 0, and the export loop skips anyone who matches no range | Validation now requires A Max = 100 and E Min = 0, and names the grade in the message. Export refuses to run if any student would be left without a grade | A Max 95 and E Min 5 each show a specific error and disable download; restoring the value clears it; row count in CSV equals student count |
| 5 | Statistics break when a marks cell holds text | `edge_cases.xlsx`: Avg `NaN`, Median `3033.5`, Max `-5` | SheetJS returns text cells as strings. `reduce((a,b)=>a+b)` then concatenates strings instead of adding, and sorting mixes strings and numbers | Every mark is converted to a number while reading the file; rows that are not numbers are rejected (see #6) | Same file: Min 0, Max 100, Avg 51.88, Median 58, checked by hand |
| 6 | Bad rows are exported silently: a row without an ID became `undefined,60,B`, duplicate IDs appeared twice, blank / "AB" / -5 / 105 marks vanished | Uploaded `edge_cases.xlsx` and downloaded the CSV | No validation of rows at all | Each row is checked for ID, course, a numeric mark within 0–100 and duplicate IDs within a course. Bad rows are skipped and listed with their Excel row number and the reason | 7 problem rows listed with correct row numbers; CSV contains only the 8 valid students, no `undefined`, no duplicates |
| 7 | Fractional marks disappear, and the format guidance contradicts itself | 79.5 was missing from the CSV (it falls between A- which ends at 79 and A which starts at 80). 80.2 was exported as `80.2`. The guidance says "rounded to the nearest integer" but gives the example 80.2 → 81 | Grade bands are whole numbers, and marks were never rounded. The guidance example is a typo | Marks are rounded to the nearest whole number on import and the user is told how many were rounded. Guidance corrected to 80.2 → 80 and 79.5 → 80 | 79.5 → 80 (A) and 80.2 → 80 (A) in the CSV, notice shows "2 fractional mark(s) were rounded" |
| 8 | A file using the brief's own headers ("Student's BITS ID", "Total Marks (out of 100)") loads but every statistic is blank or `NaN` | Uploaded `alt_headers.xlsx` | Code reads fixed keys `d["BITS ID"]` and `d["Total Marks"]`, so any other header gives `undefined` | Columns are found by keyword (`id`, `course`, `mark`/`total`). If a column is missing the user gets a clear message instead of empty results | `alt_headers.xlsx` shows correct stats; a file without those headers shows "Could not find the BITS ID, Course and Total Marks columns" |
| 9 | Reset Range crashes if no course is selected | Clicked Reset Range on a fresh page: console `TypeError: Cannot set properties of null` | The grade selects are only created after a course is chosen, but reset reads them unconditionally | Reset checks the grade inputs exist and tells the user to select a course first | No console error; message shown |
| 10 | Reset asks for confirmation twice | Clicked Reset Range: two confirm dialogs in a row | Two `confirm()` calls | Kept one | One dialog |
| 11 | Setting D Min to 0 leaves E Max blank | Set D Min = 0: E Max became an empty select and the error said Min < Max | `cascadeMaxFrom` writes `prevMin-1` = -1, which is not an option in the select, so the select goes blank (read as 0). It also loops through every lower grade instead of just the next one | Only the next grade's Max is updated, and only if the value is 0–100. Changing a Max now also updates the Min of the grade above so ranges stay touching | D Min 25 → E Max 24; C Max 45 → B- Min 46; D Min 0 no longer blanks E Max |
| 12 | A grade cannot be a single mark wide | Set D Min = 29 and D Max = 29: "Each grade must have Min < Max" | Check used `minV >= maxV` | Changed to `minV > maxV` | D = 29–29 accepted, ranges still continuous |
| 13 | Histogram bars run off the top of the chart for larger courses | ECON F211 (190 students): four bars were clipped at the top | Bar height was a fixed 12 px per student, so any bin above ~17 students overflowed | Heights are scaled to the tallest bar (or the curve peak, whichever is taller), with counts printed above bars | ECON bars and the curve fit inside the canvas; small courses still fill the height |
| 14 | Bell curve does not line up with the bars, and has an arbitrary height | ECON F211: curve ends around 95 while bars go to 100; peak unrelated to bar heights | Curve used 30 px per 10 marks while bars use 32 px; height used a magic `* 3000`; no guard for standard deviation 0 (`all_same_marks.xlsx` divides by zero) | Curve uses the same x scale as the bars and is scaled to the expected number of students per bin. Skipped when every mark is identical | Curve and bars align; flat course draws bars without errors |
| 15 | Quick changes start several chart animations at once | Instrumented `requestAnimationFrame`: one change = 8 frames in 100 ms, three quick changes = 24 | Each `drawHistogram` call starts a new animation loop without stopping the previous one, so loops fight over the canvas | Keep the frame id and `cancelAnimationFrame` before starting a new loop | Three quick changes now run one loop |
| 16 | Card "lift" and summary "pulse" animations never show | Changed a Min: the `lift` class was present at 5 ms and already gone at 65 ms | Class removed after 30 ms, but the CSS transition takes 250 ms | Remove the class after 250 ms | Card visibly lifts and settles |
| 17 | Timer counts from page load, and shows nothing until the first tick | Left the page open, then graded: the "completed grading in" message included the idle time before any file was uploaded. Timer text stayed on the placeholder for the first second | `gradingStartTime` set when the script loads; first paint only happens inside `setInterval` | Timer starts when the first course is opened and paints immediately. Dash length now uses the real circumference | Timer reads 00:00 at page load and starts when a course is opened |
| 18 | Download count is shared across courses | Downloaded course A, then course B: B's message said "second attempt" | One global `finalizeCount` | Count is kept per course; ordinals handled properly (1st…21st) | Each course's first download says "first attempt" |
| 19 | CSV breaks with commas or quotes; every download is called `grades.csv` | Instructor `Sharma, R.` pushed the name into a third column; "Course, X" had a stray leading space | Values written without CSV escaping; fixed filename; object URL never released | Values are quoted/escaped, leading space removed, file named after the course, UTF-8 BOM added so Excel reads it correctly, URL revoked after download | CSV parsed with Python's `csv` module: instructor with comma and quotes round-trips intact; filename `grades_PHY_F111_Mechanics.csv` |
| 20 | Grades can be downloaded without an instructor name | Entered a name, selected a course, cleared the name, downloaded: CSV had `Instructor,` blank | Name was only checked when the course was selected | Checked again at download | Download is blocked with a message until a name is entered |
| 21 | Switching back to the "Select a course" placeholder leaves stale or `NaN` statistics | After a re-upload, the stale course showed `NaN`; selecting the placeholder kept the old chart | `course.onchange` always ran the full update, even with no course | Empty selection clears the grading view; empty datasets show "–" instead of `undefined`/`NaN` | Placeholder clears everything; no `NaN` anywhere |
